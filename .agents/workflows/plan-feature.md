# Planejar módulo

Receba o pedido do usuário e não implemente ainda.

1. Leia as regras do projeto e os arquivos relevantes.
2. Explique em uma frase o problema que o módulo resolve.
3. Liste fluxos, regras de negócio, entidades afetadas e casos de erro.
4. Diferencie o necessário para o MVP do que pode ficar para depois.
5. Proponha arquivos a alterar, migrations necessárias e plano de validação.
6. Termine com critérios de aceite objetivos e uma pergunta de aprovação.

Quando a decisão depender de negócio, não adivinhe. Recomende uma opção e peça confirmação.
