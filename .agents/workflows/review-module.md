# Revisar módulo

Faça uma revisão somente leitura do módulo solicitado.

1. Compare a implementação com os critérios de aceite.
2. Verifique regras de domínio, RLS/autorização, dados sensíveis, upload de fotos, estoque, pagamentos e datas de retorno quando aplicável.
3. Verifique responsividade, acessibilidade e estados de erro/carregamento/vazio.
4. Rode ou indique os checks disponíveis.
5. Relate achados por severidade: crítico, alto, médio, baixo.
6. Para cada achado, cite arquivo/símbolo, cenário e correção sugerida.

Não altere arquivos. Se não houver achados relevantes, diga isso com o escopo revisado.
